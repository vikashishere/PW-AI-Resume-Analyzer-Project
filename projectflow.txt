1. Copy/clone the repo
2. Create-activate-setup venv
3. Create & setup .env file
4. Terminal1: [uvicorn api:app --reload --port 8000]
5. Terminal2: [streamlit run app.py]
6. Optional: [pytest -q]
7. Sanity checks:
- API Health: http://localhost:8000/health
- API Docs: http://localhost:8000/docs
- UI: http://localhost:8501

8. Docker command:
- [docker build -t ai-document-extractor .]
- [docker run --env-file .env -p 8000:8000 ai-document-extractor]
- Then re-run step7

9. Push project to github

10. Azure Step 1 — Create Azure Resource Group
    - Open Azure Portal.
    - Search for Resource groups.
    - Click Create.
    - Select your Azure subscription.
    - For Resource group, enter: rg-ai-extractor
    - Choose a regio- n — East US is fine.
    - Click Review + create.
    - Click Create.

11. Step 2 — Create Azure Container Registry

In Azure Portal:

Search Container registries.
Click Create.
Basics:
    - Subscription: Azure subscription 1
    - Resource group: rg-ai-extractor
    - Registry name: choose a globally unique name, e.g. "ekaextractoracr"
    - Region: East US
    - Pricing plan: Basic
    - Leave the remaining settings at their defaults.
    - Click Review + create.
    - Click Create.
    - After deployment, click Go to resource.

14. Step 6 — CICD

**Create GitHub Actions Azure identity**
- Go to Azure portal & search for 'Managed Identities'
- Click + Create
- On the creation form, you should see fields such as:
-----------------------------------
Subscription: Azure subscription 1
Resource group: rg-ai-extractor
Region: East US
Name: github-actions-identity
-----------------------------------
- Review+Create ->> Create
- Once deployment done, click: 'Click Go to resource'

**Give identity ACR push permission**
- Once deployment done, click: 'Click Go to resource'
- From this screen, click:
    ekaextractoracr → Access control (IAM)
- Click 'Add role assignment' at the bottom-left
- Select AcrPush ->> Click Next at the bottom.

- On the 'Members' tab, do exactly this:
    - Select 'Managed identity' under 'Assign access to'.
    - You should then get an option to Select members, click Select members.
    - In the selection panel: 
    - Managed identity type: User-assigned managed identity
    - Select: github-actions-identity
    - Click Select.
    - Click Review + assign.
    - If the next screen shows the role and identity correctly, click Review + assign again to actually create the permission.

- Go to your GitHub repository and open:
    Settings → Secrets and variables → Actions   

----------------------------------------------------
Now we need to give github-actions-identity permission to update the Container App. We’ll do that before adding anything to GitHub, because GitHub should only be configured after the Azure identity has all required permissions.
----------------------------------------------------

- Now, go back to Azure Portal and open:
    - rg-ai-extractor → eka-container-env → Access control (IAM)
    - Then click: 'Add role assignment'
    - In the search box, type: 'Container Apps Contributor'
    - Select Container Apps Contributor & click Next. That takes you to Members.
    - Select Managed identity.
    - Click 'Select members' & choose:
        Managed identity type: User-assigned managed identity
        Identity: github-actions-identity
        Click Select.
    - Review + Assign

- Now we'll create the GitHub/Azure OIDC connection

- Go to: Azure Portal → Managed Identities → github-actions-identity
- Then open: Settings → Federated credentials
- Click: + Add credential    
- Under Federated credential scenario, select:
    GitHub Actions deploying Azure resources & you'll need below values:
-------------------------------------------------
Organization: xxxxxx
Organization ID: xxxxxx
Repository: xxxxxx
Repository ID: xxxxxx
Entity: select Branch
For the branch, enter/select main
Name: github-main
Leave Issuer URL and Audience as they are.    
-------------------------------------------------

*** Use below github navigation to get these values ***
---
- GitHub → AI-Doc-Extractor-Azure-CICD → Settings → Actions →
On the left sidebar, under Actions, click: OIDC GitHub
---

- In Azure, click Overview for github-actions-identity, We need these three values:
    - Client ID
    - Subscription ID

- We'll also need 'Tenant ID', follow this navigation:
    In the Azure portal:
        - Search for Microsoft Entra ID in the top search bar.
        - Open Microsoft Entra ID.
        - On the Overview page, look for Tenant ID.

- Next step: Add the 3 GitHub Secrets, Go to your GitHub repository:
    - Settings → Secrets and variables → Actions
    - Then click New repository secret.
    - Create these three secrets, one at a time:
--------------------------------------------------
| Secret name             | Value                |
| ----------------------- | -------------------- |
| `AZURE_CLIENT_ID`       | Your Client ID       |
| `AZURE_TENANT_ID`       | Your Tenant ID       |
| `AZURE_SUBSCRIPTION_ID` | Your Subscription ID |
--------------------------------------------------
